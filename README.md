## ⚙️ Funktionen
- Realistische Nachbildung der BR481 Innenanzeige
- Alle Zustände des Ablaufs
- Freie Linienwahl aller Berliner S-Bahn Linien
- Freie Auswahl des Zielbahnhofs auf der Linie
- Freie Auswahl der aktuellen Position
- Einstellbare Ausstiegsseite

## 💻 Lokal ausführen
> [!NOTE]
> Der aktuelle Weg mit Python + Flask ist **temporär** und wird später eventuell vereinfacht.

1. **Repository klonen:** `git clone https://github.com/bxsti-dev/Br481-Innenanzeige-Simulator.git && cd Br481-Innenanzeige-Simulator`
2. **Voraussetzung:** [Python 3](https://www.python.org/) installiert haben
3. **Bibliotheken installieren:** `pip install flask`
4. **Server ausführen:** `python main.py`
5. **Aufrufen:** Im Browser `http://127.0.0.1:5000` öffnen
